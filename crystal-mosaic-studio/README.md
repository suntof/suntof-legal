Current policy scope:

- Capacitor Android shell with Google Mobile Ads and User Messaging Platform support.
- Android cloud backup and device-to-device transfer are disabled for local game data.
- Optional Firebase identity, rankings and private cloud backup. Supported releases offer Google on Android, Google/Apple on iOS, and verified email/password recovery; core gameplay requires no account. Provider display name/photo URL, when supplied, stay separate from the public ranking profile.
- Optional one-time Remove Ads store purchase and restore; native receipts do not cross the JavaScript bridge or enter cloud backups. No payment-card access, notification SDK or first-party remote gameplay analytics.
- Privacy/deletion descriptions updated 2026-11-01 for supported social recovery and provider reauthentication, preserving separate local, ranking and cloud deletion choices. Store privacy labels are managed separately in the consoles.
