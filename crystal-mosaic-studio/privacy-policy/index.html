Crystal Mosaic Studio - Privacy

Privacy Policy

Last updated: July 15, 2026

This Privacy Policy explains how Suntof Solutions handles information for Crystal Mosaic Studio, including the current web/PWA prototype and Android SDK baseline.

Local-first gameplay Progress, settings, coins, boosters, gallery unlocks, and event claims are stored on your device.
Optional local QA log The local event log can be disabled, cleared, or exported from Settings.
SDKs staged, not live Ad, crash, notification, and billing integrations require production setup before live use.

1) Who we are

Crystal Mosaic Studio is operated by Suntof Solutions. For privacy, support, or deletion requests, contact suntof.apps@gmail.com.

2) Scope of this policy

This policy covers the current local-first prototype and Android SDK baseline. It must be reviewed again before enabling production ads, purchases, remote analytics, crash reporting, cloud saves, login, subscriptions, push notifications, or any third-party SDK that changes data collection.

3) Information processed by the current build

  • Local game progress: completed levels, active puzzle state, moves, coins, boosters, gallery pieces, pack rewards, achievements, daily quest state, and weekly event claims.
  • Local settings: sound, motion, dark mode, haptics, symbols, reminders, privacy review state, and local event-log preference.
  • Optional local QA event log: gameplay events used for local testing, such as level starts, completions, hints, booster use, errors, and UI actions. This log can be disabled, cleared, or exported from Settings.
  • Support communications: if you email us, we receive the email address and information you include in your message.

4) SDK and network status

The Android baseline is prepared with Capacitor and staged SDK dependencies for Google Mobile Ads, Google User Messaging Platform consent, Firebase Crashlytics, local notifications, and future Google Play Billing. These integrations are not considered production live until real app IDs, consent flow, store disclosures, and release configuration are completed.

  • No account registration or login in the current prototype.
  • No production ad serving is enabled in the current prototype.
  • No in-app purchase products are active in the current prototype.
  • No remote gameplay analytics or cloud save is active in the current prototype.
  • No precise location, contacts, camera, microphone, or files access is required for core gameplay.

5) How information is used

  • To run the game, save progress, and remember settings on your device.
  • To let you export/import local save data.
  • To support local QA and debugging when the optional event log is enabled.
  • To respond to support, privacy, and deletion requests.

6) Sharing and third parties

The current prototype does not send gameplay data to our servers. If you export save or event-log JSON and share it manually, the destination you choose may process that file under its own terms and privacy policy.

This policy page is hosted on GitHub Pages. GitHub may process basic technical web logs when this page is visited.

7) Retention and deletion

  • Local game data remains on your device until you reset progress, clear browser/app data, or uninstall the app.
  • The optional local QA event log can be disabled or cleared from Settings.
  • If you send information to us by email, you can request deletion by contacting suntof.apps@gmail.com.

8) Children

Crystal Mosaic Studio is intended as a casual puzzle game for a broad audience. We do not knowingly collect personal information from children. If you believe a child has sent us personal information, contact us and we will take appropriate action.

9) Security

We use reasonable safeguards for information received through support emails. No method of storage or transmission is perfectly secure, so please avoid sending sensitive personal information in support messages or exported local JSON files.

10) Changes

We may update this policy when the game changes. Significant data-flow changes, such as production ads, purchases, remote analytics, crash reporting, or cloud features, require this policy and store disclosures to be updated before release.
