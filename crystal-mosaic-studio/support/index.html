Support

Last updated: August 26, 2026

For support, test feedback, privacy requests, or deletion requests related to Prism Mosaic: Gem Sorting, contact us by email.

Email suntof.apps@gmail.com
Privacy requests Use the same email for access, correction, deletion, and exported-report removal requests.
Testing notes Include device model, iOS, Android, or browser version, level title, and what happened.

How to contact us

Email suntof.apps@gmail.com. Please include the app name, your device model, iOS/Android/browser version if known, and a short description of the issue.

Local save and event files

The app can export local save data and optional QA event logs from Settings. Send these files only if you are comfortable sharing local gameplay diagnostics such as level attempts, moves, hints, boosters, timing, and settings.

Privacy and deletion requests

If you sent us exported data and want it deleted, email us from the same address you used to send the file when possible. We may ask for enough detail to locate the message or file.
